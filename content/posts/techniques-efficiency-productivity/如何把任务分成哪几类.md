大多数人的待办清单都有同一个问题：所有事情被平铺在一张纸上，"回客户邮件""洗杯子""写那个能改命的项目"排在一起，看起来一样重要，结果就是每天忙到晚上，回头一看，真正重要的事一件没动。问题不在于你不够努力，而在于你没有给任务分类。时间和注意力都是有限的，一件事值不值得做、什么时候做、用多少精力做，取决于它到底在你的人生里起什么作用：是在改变你的未来，是在保住你的现实，只是让生活不卡顿，还是在白白吞掉你的时间。下面这套分级，就是按这个标准把所有任务拆成几类：R、S、A、B，再加上一个必须警惕的 C。分清楚了，你才知道哪些该死磕，哪些该速清，哪些该直接掐掉。

#### 实现自我R任务/主线S-Core任务/主线S-Support任务/致命A任务/普通A任务/杂碎B任务/混沌C情况

- **实现自我R任务**：享受自由，真正享受已经拥有的时间。旅行、游戏、美食、艺术、体验世界、真正想玩的游戏、主动休息。
- **主线S-Core任务，主线S-Support任务** ：最高优先级改命，改变你未来身份/阶层/单价/抬段位的全部东西，"这辈子我想砸出来的主武器" ，长线筹码，成长项目，旗舰项目，强复利 / 强杠杆，高度可替代性低，非常消耗深度思考 / 创造力，不做也活得下去，但做了可以抬你未来单价和筹码
- S 里面再分两层，但统称 S：
  - **主线S-Core任务**：捶打主武器本体，情报体系 / 舆论操盘模型 / 文化地图
  - 例子：能直接拿去卖钱的报告、体系化内容，个人"母站"、品牌中枢、大系统框架
  - **主线S-Support任务**：给主武器装零件 / 铺路，搭脚手架
  - 例子：为主项目补技能（写作、建站、自动化），为主项目做案例、做模板、整理素材库，优化S-Core工作流
- **致命A任务**：不做会挨现实铁拳的任务，直接决定你这30天内能不能活下去，不做这件事，30天内，我会不会在现实上被砍一刀？是，就算A。例外：准备周期长的事（签证、法律、大额财务），按缓冲规则提前升级——剩下的时间 ≤ 做完它需要的时间 × 2，就算致命A，不管离截止还有多久。
- 例子：即将到硬期限且可能造成明确损失，健康：找医生、约诊、看诊、长期用药管理，身份 / 法律 / 签证、材料准备、关键邮件、表格、补件，必须交付的工作 / 项目，必须回的客户 / 合作消息，催款、确认收款，大额账单 / 信用 / 罚款：不处理会上 collection、罚很多钱、信用炸
- **普通A任务** ：维持现实正常运转的必要任务，不做不会马上挨刀，但拖着会滚雪球，迟早变成致命A。定义：不做这件事，30天内没事，但一直拖下去会不会变成"被砍一刀"？是，就算普通A。损失小、有缓冲、能补救，但必须定期清掉，别让它升级。升级规则：离挨刀进入30天内，或者剩下的时间 ≤ 做完它需要的时间 × 2，直接升致命A。
- 例子：还没到期但迟早要交的材料（报税资料整理、证件快到期前提前续）、定期体检 / 洗牙 / 复查、日常账单自动扣款核对、续费或取消订阅、补日用品 / 囤必需品、回非紧急但不能不回的邮件和消息、维护重要人脉（该联系的人别失联）
- **杂碎B任务** ：机械、步骤清晰、不需要太多思考，以及不做会恶心 / 卡顿 / 乱，但做完并不会直接提高你阶层，只是"不卡"。
- 例子：洗头 + 吹发型，丢垃圾、洗杯子、收拾桌角、整理衣服，上传文件、拍照存档、重命名、整理文件夹，登陆网站点确认、对几笔小账、记流水
- **混沌C情况**：既没有推进未来，也没有维护现实，更没有产生真正体验价值，却持续吞噬时间和注意力的行为。
- 例子：无意识刷短视频，本来查一个东西，最后乱点两个小时，毫无目的地刷新社交媒体，同一类信息反复查、反复确认，并不快乐但停不下来的游戏/视频，坐着发呆很久，却既没有恢复也没有思考成果，本来准备工作，结果不断找"相关资料"逃避真正任务
