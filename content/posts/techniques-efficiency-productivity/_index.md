# R / S / A / B / C 任务分类体系

这套分类不是单纯按“紧急程度”排队，而是先判断一件事究竟属于：**实现人生、改变未来、生存现实、日常维护，还是纯粹吞噬时间。**

---

## 实现自我 R 任务

**定义：真正使用自己已经拥有的人生和自由。**

旅行、游戏、美食、艺术、体验世界、真正想玩的游戏、主动休息。

R 不是“浪费时间”，也不是混沌 C。  
判断标准是：**这件事本身就是我愿意拿人生时间去换的体验。**

---

## 主线 S 任务

**最高优先级的改命任务。**

改变未来身份、阶层、单价、筹码和能力上限的东西；是“这辈子我想砸出来的主武器”。

共同特征：

- 长线筹码
- 成长项目 / 旗舰项目
- 强复利 / 强杠杆
- 高度不可替代
- 非常消耗深度思考 / 创造力
- 不做也能暂时活下去，但做成以后会明显抬高未来单价和选择权

S 再分为两层，但统称为 **S**。

### S-Core：主线核心

**直接捶打主武器本体。**

例如：

- 情报体系
- 舆论操盘模型
- 文化地图
- 能直接拿去卖钱的报告
- 体系化内容
- 个人“母站”
- 品牌中枢
- 大系统框架

判断标准：

> **这件事完成后，主武器本体是不是直接变强、变厚、变得更能卖、更难替代？**

如果是，就是 S-Core。

### S-Support：主线支援

**给主武器装零件、铺路、搭脚手架。**

例如：

- 为主项目补技能：写作、建站、自动化
- 为主项目做案例
- 做模板
- 整理素材库
- 优化 S-Core 工作流

判断标准：

> **它本身不是主武器，但能不能明显提高 S-Core 的速度、质量、产能或可持续性？**

如果是，就是 S-Support。

---

## 致命 A 任务

**不做会挨现实铁拳的任务。**

它直接关系到未来 **1 天—12 个月** 内会不会出现明确的现实损失。

唯一判断问题：

> **不做这件事，1 天—12 个月内，我会不会在现实上被砍一刀？**

如果答案是“会”，就是致命 A。

典型致命 A：

- 即将到硬期限，而且错过会造成明确损失
- 健康：找医生、约诊、看诊、长期用药管理
- 身份 / 法律 / 签证 / 庇护：材料准备、关键邮件、表格、补件
- 必须交付的工作 / 项目
- 必须回复的客户 / 合作消息
- 催款、确认收款
- 大额账单 / 信用 / 罚款：不处理会进 collection、产生严重罚款或信用受损

**致命 A 可以临时插队。**  
因为它不是“更有价值”，而是“不处理会直接造成损失”。

---

## 普通 A 任务

**与未来 1–2 年的生存盘直接相关，但目前还没有形成“马上不做就挨刀”的硬期限。**

它们通常不会因为今天没做就立即爆炸，但如果长期不做，会让现金流、健康、身份稳定、工作能力或现实容错率持续下降。

例如：

- 找收入来源、维护稳定现金流
- 正常求职、接单、客户开发
- 没有临近截止日期的重要行政事项
- 常规财务管理
- 预防性健康安排
- 提前处理未来会变成致命 A 的事项

判断标准：

> **它是不是在给未来 1–2 年的现实生存打底，但现在还没有明确的近期铁拳？**

如果是，就是普通 A。

---

## 杂碎 B 任务

**机械、步骤清晰、不需要太多思考；不做会恶心、卡顿、变乱，但做完不会直接抬高阶层。**

本质是：

> **维护系统，让现实别卡住。**

例如：

- 洗头 + 吹发型
- 丢垃圾
- 洗杯子
- 收拾桌角
- 整理衣服
- 上传文件
- 拍照存档
- 重命名
- 整理文件夹
- 登录网站点确认
- 对几笔小账
- 记流水

B 不应该抢 S-Core 的黄金时间。  
能塞进碎片时间、低能量时间、自由时间，就不要占深度工作时段。

---

## 混沌 C 情况

**既没有推进未来，也没有维护现实，更没有产生真正体验价值，却持续吞噬时间和注意力的行为。**

例如：

- 无意识刷短视频
- 本来查一个东西，最后乱点两个小时
- 毫无目的地刷新社交媒体
- 同一类信息反复查、反复确认
- 并不快乐但停不下来的游戏 / 视频
- 坐着发呆很久，但既没有恢复，也没有思考成果
- 本来准备工作，结果不断找“相关资料”逃避真正任务

C 和 R 最大的区别：

- **R：我主动选择这段体验，而且它本身值得。**
- **C：我没有真正选择，只是注意力被吞掉。**

---

# 实际执行规则

遇到一件事时，按下面顺序判断：

1. **这是我真正想拿人生去换的体验吗？**  
   是 → R。

2. **它是否直接增强我的主武器和长期筹码？**  
   是 → S-Core。

3. **它是否明显支援 S-Core？**  
   是 → S-Support。

4. **1 天—12 个月内不做，会不会出现明确现实损失？**  
   是 → 致命 A。

5. **它是否直接维持未来 1–2 年的生存盘，但还没有硬期限？**  
   是 → 普通 A。

6. **它是否只是维护环境、行政、文件和生活系统，让现实不卡？**  
   是 → B。

7. **如果以上都不是，而且它还在持续吞噬注意力。**  
   → C。

---

# 时间分配原则

- **S-Core**：优先占用最好的深度思考时间。
- **S-Support**：围绕 S-Core 服务，不反客为主。
- **致命 A**：出现明确现实风险时立即插队处理。
- **普通 A**：稳定维持生存盘，防止未来升级成致命 A。
- **B**：尽量塞进碎片时间、低能量时间、自由时间。
- **R**：主动安排，真正兑现人生，而不是无限延期。
- **C**：识别后尽快截断，不给它伪装成“休息”“研究”或“准备工作”。
