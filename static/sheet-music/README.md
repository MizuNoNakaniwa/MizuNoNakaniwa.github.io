# My Sheet Music / 我的琴谱

琴谱原文件统一放在这个目录。

Put all original sheet-music files in this directory.

建议文件类型 / Recommended formats:
- PDF
- PNG / JPG / WEBP
- MuseScore (.mscz / .mscx)
- MusicXML (.musicxml / .xml)
- MIDI (.mid / .midi)

命名建议 / Naming:
`曲名 - 作曲者 - 版本.ext`

例如 / Example:
`River Flows in You - Yiruma - Piano.pdf`

网页中的公开文件地址格式：
`/sheet-music/文件名`

琴谱文件放这里。
